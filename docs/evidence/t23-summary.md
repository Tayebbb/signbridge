# T23 — opaque-origin renderer spike

2026-11-03 (Asia/Dhaka). PASS in Chromium and Microsoft Edge, headless on one Windows host using SwiftShader software WebGL. This demonstrates technical renderability only.

- Unmodified remote UEA CWASA **vhg2026**, standard Anna avatar.
- Host and renderer load from the same local origin through a transparent HTTP forwarding server. Server-side capture records request origin, cookie presence and upstream response status; no real cookie/token values are recorded.
- The frame has **`sandbox="allow-scripts"`**, without `allow-same-origin`.
- The exact research fixture is copied with only its gloss values lowercased. Both engines report **5 units / 164 generated frames**, with **164 frame events** and all five expected lowercase IDs in order. The terminal duplicate sign hook is deduplicated only for ID comparison.
- Each accepted hook carries one matching `instanceId`; the host checks `event.source`, instance identity and the Zod payload schema. Unit tests reject foreign sources, stale instances and malformed payloads.
- A synthetic HttpOnly, Secure, SameSite=Lax host cookie is present on a host health request (HTTP 200). The frame's `fetch('/api/health', {credentials:'include'})` reaches the capture server with **`Origin: null`**, **no Cookie header**, and an upstream HTTP 200. JavaScript cannot read the response because the API grants no CORS access to the opaque origin.
- **No CSP violations or page errors** under the final policy in either browser.
- Initial policy evidence: `t23-csp-initial.json` records six `script-src-attr` violations from autogenerated GUI event attributes. The renderer alone now permits inline script attributes. Script elements still require self or UEA; neither inline script elements nor eval are permitted. No parent-page policy was loosened.

Measured working renderer policy:

```text
default-src 'none'; script-src 'self' https://vhg.cmp.uea.ac.uk; script-src-attr 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://vhg.cmp.uea.ac.uk; connect-src 'self' https://vhg.cmp.uea.ac.uk; img-src https://vhg.cmp.uea.ac.uk blob: data:; worker-src blob:; base-uri 'none'; form-action 'none'; frame-ancestors 'self'
```

The same-origin trusted-code fallback is **not needed** by this spike. Standby instances, cancellation replacement and the player scheduler remain later-phase work. This result does not establish BdSL correctness, linguistic review, comprehension, mobile performance, or remote-server availability.
