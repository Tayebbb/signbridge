# Limitations

Experimental · not reviewed by a BdSL signer.

- Technical renderability is the only evaluated evidence category: 20/20 sampled corpus files (Phase 2), 12/12 curated assets and six production segments replayed in Chrome/Edge (Phase 7), on one Windows host with software WebGL. These sets are not claimed as disjoint. Linguistic correctness: none. User comprehension: none.
- The unrelated corpus entries in the fixture do not form a claimed translation.
- Software WebGL on a Windows host does not establish performance or compatibility on mobile hardware.
- UEA serves the remote, unmodified renderer with no availability warranty. The host reports loading until `avatarready`; a missing engine never establishes completed signing.
- The upload/API/job pipeline and production adapters are implemented. Phase 7 exercised real OpenAI, Neon, private Blob and Workflows, including actual mid-run cutover. Local tests still use explicit labelled fake fixtures. The local player/workspace, corrections, sharing and deletion UI are implemented. There is no qualified review UI or claimed language-quality result.
- PGlite files are local development storage, not durable Vercel storage. Production requires an owner-approved Neon configuration. `/api/health` checks DB connectivity, the required recovery-schema column and production adapter configuration. It makes no paid provider call and does not establish signing quality or full provider availability.
- The owner supplied the official event sticker and confirmed its organizer provenance. The original image is used unchanged in the top banner.
- The fixed XML whitelist excludes 131 distinct full-release files with nonmanual elements outside that whitelist, alongside 43 other rejected hashes. Their source paths and reasons remain in the import evidence. These exclusions limit coverage; no motion or nonmanual content was silently removed to make an asset pass.
- The original local sample seed admits 20 successfully probed assets. The later full sweep admitted 2,927 of 2,934 accepted hashes into production; seven failed both initial rendering and a separate recheck, so remain ineligible. The 174 original XML quarantines remain excluded. [Current evidence and normal-video follow-up](COVERAGE-FOLLOWUP.md).
- Retrieval stemming and independent Bangla detectors are deliberately coarse. Ambiguous words and suffixes can produce conservative blocking; they do not validate BdSL semantics. P3 checks candidate provenance or exact labels, and never uses lossy retrieval text directly as proof.
- The unchanged-caption normal-video follow-up generated and played nine units, but all four segments still have critical gaps and none count as fully signed. More technically rendered vocabulary does not establish natural-language coverage, correct grammar or comprehension.
- Offline strict-schema contract tests cover the published OpenAI subset. Real Sol Responses/structured outputs were also exercised in Phase 7; schema acceptance does not establish model or signing quality.
- Race suites cover PGlite and a disposable local PostgreSQL 16.11 server. Phase 7 adds actual Neon/Blob/Workflow deployment checks, not a claim that every race was rerun on Neon. PGlite serializes transactions; PostgreSQL tests explicitly observe blocked sessions before releasing project/cache locks.
- Logical project deletion hides data immediately. Physical cleanup can wait up to the upload lease's remaining 15-minute reservation window; this prevents late uploads from escaping purge. Reconciliation must continue running, with at least daily full retention sweeps for the 96-hour cleanup target. Hobby cron jitter and outages can exceed that target; no fixed deletion deadline is guaranteed.
- Initial dispatch has bounded server retries even if the creator tab closes. Five failed unclaimed dispatches terminate with an explicit retryable error. Independent scheduled reconciliation and the daily Vercel fallback remain best effort. Production uses Workflows; the in-process adapter is development-only and no lease transport is claimed.
- Shared links grant anyone holding the URL read access. New source reads check authorization on every GET/range request; an in-flight read can finish after revocation. Shared views cannot mutate the project. Creator cookies last 180 days, and a saved recovery key can restore access while invalidating earlier creator sessions. Save the key and creator URLs privately.
- Real processing sends captions, context and title to OpenAI, potentially including personal data. Requests set `store:false`; this does not establish zero provider retention. Upload only permitted material.
- The automatic model circuit requires five recent real attempts, at least three errors and a failure rate above 20%; its cooldown expires after ten minutes. The persistent administrator stop is separate. Hard spend reservations remain authoritative. Saved replay stays model-free; the remote avatar service and WebGL remain dependencies. Fake fixtures are excluded from real-provider metrics.
- Tested browsers currently run the remote engine, but a staged-browser console reported XSLT deprecation. This dependency needs continued compatibility testing and a supported engine upgrade path; no future-browser guarantee is made.
- Optional anchors, learner pace presets, simultaneous overlay, embeddings and ASR are cut at the feature freeze. Public deployment and curated demo gates passed in Phase 7. Real-device observations remain NOT RUN.
